# Refer: hybrid search over internal docs

Refer answers questions from internal Markdown/TXT docs and shows the evidence, highlighted. The backend is **FastAPI + LangChain + Google Gemini**, and the frontend is **Next.js + Tailwind**.

Retrieval combines **BM25 keyword search** (exact terms like `EXP-204`) with **vector search** (meaning, e.g. "vacation" → "annual leave"). LangChain's `EnsembleRetriever` merges the two result lists with **Reciprocal Rank Fusion**: `score = Σ 0.5/(60 + rank)`.

```
docs/*.md|*.txt → MarkdownHeaderTextSplitter → RecursiveCharacterTextSplitter
   ├→ BM25Retriever ─────────────────────────────┐
   └→ Gemini embeddings → InMemoryVectorStore ───┴→ EnsembleRetriever (RRF) → top-k
                                                     → prompt | Gemini | parser → answer with [n] citations
```

## Project structure
```
hybrid-rag/
├── backend/                 FastAPI + LangChain (Python)
│   ├── app/
│   │   ├── config.py        settings from .env
│   │   ├── llm.py           Gemini chat + embedding models
│   │   ├── loader.py        read .md / .txt files
│   │   ├── chunker.py       heading-aware chunking
│   │   ├── retrieval.py     BM25 + vector + RRF fusion
│   │   ├── generator.py     grounded answer chain
│   │   ├── ingest.py        build / save / load the index (CLI)
│   │   └── main.py          API: /ask, /ingest, /health
│   ├── tests/               pytest (no API key needed)
│   ├── docs/                the internal docs to search
│   ├── index/               generated by ingest (git-ignored)
│   ├── requirements.txt
│   └── .env.example         copy to .env and add GOOGLE_API_KEY
└── frontend/                Next.js 15 + Tailwind v4
    ├── src/app/             layout, page (chat state), global styles
    ├── src/components/      Header, Composer, TurnView, SourceCard, RankBadges
    ├── src/lib/             API client, types, citation parser
    └── next.config.ts       proxies /api/* → backend (no CORS needed)
```

## Setup
**1. Backend** (first terminal)
```
cd backend
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # then paste your key from https://aistudio.google.com/apikey
python -m app.ingest docs
uvicorn app.main:app --reload   # http://localhost:8000
```

**2. Frontend** (second terminal)
```
cd frontend
npm install
npm run dev                     # http://localhost:3000
```

Open http://localhost:3000. To point the frontend at a different backend, set `BACKEND_URL`.

Note: doc chunks are sent to Google's API for embedding and answering.

## Try it
| Question | What to notice |
|---|---|
| `What is the hotel cap in EXP-204?` | BM25 nails the exact code |
| `How much vacation do I get?` | Vector search finds "Annual Leave" with no shared keywords |
| `What do I do if I lose my laptop?` | Hybrid: both retrievers agree, so the chunk gets the highest RRF score |

## API
- `POST /ask` with `{"question": "...", "mode": "hybrid|bm25|vector", "top_k": 5}` returns `{answer, mode, sources[]}`
- `POST /ingest` re-indexes `backend/docs/`
- `GET /health` returns `{status, indexed, config_error}`

## Config (`backend/.env`)
`GOOGLE_API_KEY`, `CHAT_MODEL` (default `gemini-3.5-flash-lite`), `EMBED_MODEL`, `REQUEST_TIMEOUT`, `MAX_RETRIES`, `CHUNK_SIZE`, `CHUNK_OVERLAP`, `TOP_K`, `RRF_K`, `DOCS_DIR`, `INDEX_DIR`.
